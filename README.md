## 🌟 The 3 Evaluation Pillars

1. **Pillar 01 · Cost Analysis & Budget Sliders**:
   - Out-of-state tuition, mandatory student fees, and estimated regional room & board expenses.
   - Interactive budget filters (e.g. Find colleges with **Total Cost ≤ $55,000/year**).
   - Profiles affordable public options such as Minot State University ($21,213), Bemidji State ($23,600), and SMSU ($24,757).
2. **Pillar 02 · Legitimacy & Accreditation Verification**:
   - **DAPIP Accreditation**: Official U.S. Department of Education recognition check.
   - **SEVP / F-1 Certification**: Verification of legal authority to issue I-20 documentation for international students.
   - **STEM OPT Eligibility**: Program CIP code checking for 36-month post-graduation work authorization.
3. **Pillar 03 · Student Experience & Outcome Metrics**:
   - First-to-second year retention rates and 6-year graduation rates.
   - Deep-link integrations searching actual student discussions across Reddit, LinkedIn, and YouTube.

## 🇨🇳 中文介绍 · AILatest Path

### 为什么需要 Path？
赴美留学花费高昂，但市场上充斥着排名广告与中介包装，学生常常面临“高昂学费读水校”或“误入非认证机构”的风险。

**AILatest Path 专注于真实性价比与资质合规性**：
1. **量化年度总开支**：拆解州外学费、强制杂费与当地真实租房生活开销，支持按「5.5 万美元以下」等总预算区间一键筛选高性价比公立高校。
2. **官方权威资质交叉核验**：
   - 美国教育部 DAPIP 机构认证状态可核查；
   - 美国国土安全部 SEVP 认证与 F-1 学生签证（I-20）发放资质确认；
   - 专业 CIP 代码与 36 个月 STEM OPT 延期资质验证。
3. **真实毕业生结果与社交口碑**：汇集一年级留校率、毕业率以及跨平台（Reddit、YouTube 等）真实学生在读体验。
