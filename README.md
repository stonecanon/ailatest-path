## 🌟 核心对比维度

- **真实学杂费与隐性开支**：不仅看官网标准 Tuition，更拆解地域生活成本、住宿支出与保险费用。
- **奖学金发放率与工读机会**：统计不同院校向国际学生提供 Merit-based / Need-based 资助的真实比例。
- **毕业薪酬中位数与 OPT 留美政策**：量化毕业生首年薪酬中位数与行业雇主偏好。
